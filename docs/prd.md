
## 一句话定义

> **一种“东方留白感 × Apple 式克制 × 高级生活方式品牌 × 轻玻璃材质”的工具产品设计。**
>
> 它不是传统意义上的“工具站”，而应该更像一个**具有个人品牌气质的数字工作空间 / 数字工作台**。

---

## 完整设计风格 Prompt

```text
Design a premium personal-brand digital workspace, NOT a conventional online tools website.

The overall visual language should combine:
- Eastern minimalism and generous whitespace
- Apple-like restraint and refinement
- Premium editorial / lifestyle brand aesthetics
- Soft futuristic digital interface
- Subtle glass and translucent material
- Calm, immersive atmosphere
- Elegant personal identity

The design should feel like a carefully designed digital product from an independent designer,
rather than a collection of utilities assembled into a website.

━━━━━━━━━━━━━━━━━━━━━━
1. CORE DESIGN PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━

The most important concept is:

"Less interface, more atmosphere."

Do not try to fill the screen with information.

Prioritize:
- whitespace
- visual breathing room
- hierarchy
- calmness
- material feeling
- typography
- subtle motion
- visual storytelling

The user should feel:
"这不是一个工具网站，而是一个属于某个人的数字工作空间。"

Avoid the visual language of:
- generic SaaS dashboards
- developer portals
- admin panels
- traditional utility websites
- dense tool grids
- excessive cards
- excessive badges
- excessive buttons
- excessive gradients
- cyberpunk
- dark mode tech aesthetics

━━━━━━━━━━━━━━━━━━━━━━
2. COLOR SYSTEM
━━━━━━━━━━━━━━━━━━━━━━

Never use a black or dark background.

Primary background:
- warm white
- ivory white
- very light cool gray
- extremely subtle lavender-blue tint

Approximate palette:

Background:
#F8F9FC
#FAFAF8
#F5F7FB

Surface:
#FFFFFF
with 70–90% opacity

Primary accent:
soft periwinkle blue
soft lavender
very light violet

Accent examples:
#6E82FF
#8998FF
#A7AEFF
#C8C9FF

Secondary subtle colors:
mist blue
pale lavender
soft peach
very pale sage

Saturation must remain low.

The interface should never feel colorful or childish.

Colors should appear mainly through:
- subtle gradients
- light reflections
- small icons
- active states
- translucent objects

rather than large saturated color blocks.

━━━━━━━━━━━━━━━━━━━━━━
3. BACKGROUND
━━━━━━━━━━━━━━━━━━━━━━

The background should feel almost physical.

Use:
- soft white space
- extremely subtle radial gradients
- blurred light
- translucent shadows
- faint atmospheric haze
- very soft blue/lavender illumination

Optional decorative elements:
- translucent glass rings
- polished stone
- crystal
- water surface
- dried flowers
- soft fabric
- abstract sculptural objects

These objects should be used as visual atmosphere,
NOT as functional UI elements.

They should feel like a premium product advertisement.

Never use:
- busy illustrations
- neon effects
- star fields
- cyber grids
- glowing particles everywhere
- obvious 3D gaming assets

━━━━━━━━━━━━━━━━━━━━━━
4. LAYOUT
━━━━━━━━━━━━━━━━━━━━━━

Use a very spacious composition.

Desktop layout:

Left:
a very narrow vertical navigation rail.

Center:
the main content.

Right:
mostly empty breathing space.

The sidebar should NOT look like a traditional SaaS sidebar.

Use:
- small icons
- extremely subtle labels
- large vertical spacing
- minimal separators

Example navigation:

ever
│
⌂
首页
│
◇
工具
│
☆
收藏
│
◷
历史
│
...
│
☼
○

The sidebar should feel almost like a gallery navigation,
not an administration menu.

━━━━━━━━━━━━━━━━━━━━━━
5. BRANDING
━━━━━━━━━━━━━━━━━━━━━━

The personal brand should be extremely subtle.

Use a short lowercase wordmark.

Example:

ever

The logo should be:
- lowercase
- elegant serif or refined geometric typography
- extremely simple
- memorable
- not a typical tech logo

The brand should feel like:
an independent designer's personal digital studio.

Avoid:
- complicated logos
- shield logos
- hexagons
- AI robot symbols
- generic startup logos
- gradients inside the logo

━━━━━━━━━━━━━━━━━━━━━━
6. TYPOGRAPHY
━━━━━━━━━━━━━━━━━━━━━━

Typography is one of the main visual elements.

Use large elegant headlines.

Chinese typography should have:
- generous line-height
- slightly literary feeling
- thin to regular weight
- strong contrast between headline and supporting text

Example:

让工具，
回归思考本身

"思考" can use a subtle lavender-blue accent.

Supporting text should be small and quiet:

精心打造轻盈而强大的工具集合
在这里，高效与美感并存

Do not use huge bold SaaS-style typography.

Avoid:
- excessive font weights
- uppercase English everywhere
- overly condensed fonts
- aggressive futuristic fonts

━━━━━━━━━━━━━━━━━━━━━━
7. TOOL CARDS
━━━━━━━━━━━━━━━━━━━━━━

Tool cards should NOT look like traditional utility cards.

Use very large rounded rectangles with:
- extremely subtle pastel background
- almost invisible borders
- soft shadows
- generous internal spacing

Each card should contain only:

icon
tool name
one short description
small arrow

Example:

Base64 编解码

快速进行编码
和解码

→

Do not add:
- ratings
- usage counts
- tags
- badges
- "HOT"
- "NEW"
- statistics
- multiple buttons
- excessive metadata

The card itself should be the interaction.

Cards should feel like physical objects floating gently
inside a calm digital environment.

━━━━━━━━━━━━━━━━━━━━━━
8. VISUAL MATERIAL
━━━━━━━━━━━━━━━━━━━━━━

Use a very subtle "soft glass" material.

Glass should be:
- translucent
- bright
- milky
- slightly blurred
- almost invisible

Not:
- strong glassmorphism
- heavy blur
- neon glass
- dark glass

Think:

"frosted glass in morning sunlight"

rather than:

"cyberpunk glass interface".

━━━━━━━━━━━━━━━━━━━━━━
9. HERO SECTION
━━━━━━━━━━━━━━━━━━━━━━

The hero section should feel like a premium brand landing page.

Very little information.

Example:

让工具，
回归思考本身

精心打造轻盈而强大的工具集合
在这里，高效与美感并存

[ 开始探索 → ]

Beside the typography:
one single abstract physical object.

For example:
- translucent glass ring
- floating crystal
- polished stone
- glass sphere
- soft sculptural object

The object should occupy significant visual space,
but remain visually quiet.

It should create a sense of:
"art + technology".

━━━━━━━━━━━━━━━━━━━━━━
10. TOOL PAGE
━━━━━━━━━━━━━━━━━━━━━━

Individual tool pages must maintain the same philosophy.

Do NOT create a typical developer-tool interface.

For example, Base64:

Base64 编解码

快速进行编码和解码

Then one large central workspace.

Two large input/output areas:

输入                    输出

┌────────────────┐     ┌────────────────┐
│                │  ↔  │                │
│                │     │                │
│                │     │                │
│                │     │                │
└────────────────┘     └────────────────┘

Everything should be spacious.

Only essential controls:

编码 / 解码

UTF-8

复制

清空

The workspace should feel almost like
a premium writing application.

Not like a developer console.

━━━━━━━━━━━━━━━━━━━━━━
11. ICONOGRAPHY
━━━━━━━━━━━━━━━━━━━━━━

Icons should be:
- thin
- geometric
- minimal
- monochrome or very lightly colored

Use icons as small visual accents.

Do not make icons large colorful app logos.

━━━━━━━━━━━━━━━━━━━━━━
12. DEPTH AND SHADOW
━━━━━━━━━━━━━━━━━━━━━━

Use extremely soft shadows.

The interface should have almost no hard borders.

Depth should come from:
- light
- translucency
- soft shadow
- overlapping layers
- atmospheric gradients

Avoid:
- strong drop shadows
- black borders
- hard outlines
- excessive elevation

━━━━━━━━━━━━━━━━━━━━━━
13. MOTION
━━━━━━━━━━━━━━━━━━━━━━

Motion should be slow and subtle.

Examples:
- cards gently rise when hovered
- glass objects slowly move
- gradients breathe very slowly
- page transitions use soft fade/slide
- buttons have subtle scale feedback

The feeling should be:

"breathing"

not:

"animation showcase".

━━━━━━━━━━━━━━━━━━━━━━
14. INTERNATIONAL DESIGN
━━━━━━━━━━━━━━━━━━━━━━

The interface should work naturally in both Chinese and international environments.

Avoid overly Chinese visual decoration.

Use:
- simple Chinese typography
- restrained English labels where appropriate
- universal iconography
- intuitive interaction patterns

The design language should feel globally understandable,
while still having a subtle Eastern sense of restraint and whitespace.

━━━━━━━━━━━━━━━━━━━━━━
15. MOST IMPORTANT RULE
━━━━━━━━━━━━━━━━━━━━━━

The website must NOT look like:

"Here are 30 online tools."

Instead it should look like:

"A personal digital studio containing a collection of carefully crafted tools."

The tools are secondary.

The brand, atmosphere and experience are primary.

The user should remember the website itself,
not merely remember "that website has a JSON parser".

━━━━━━━━━━━━━━━━━━━━━━
16. DESIGN KEYWORDS
━━━━━━━━━━━━━━━━━━━━━━

Use these concepts:

calm

Avoid these concepts:

generic utility website
```

### 如果让我给这个风格起一个名字

我会把它定义成：

> **「Quiet Digital Studio」——静谧数字工作室**

或者中文叫：

> **「留白数字工作室」**

核心不是“高级科技感”，而是 **“让数字工具拥有类似生活方式品牌的气质”**。

这也是为什么最后一版比前面的版本更接近你想要的感觉：**它开始弱化“工具站”的身份，强化“品牌空间”的身份。**

以后你让 AI 继续设计的时候，最重要的一句话其实就是：

> **不要设计一个工具网站，要设计一个“拥有工具的个人数字空间”。**
